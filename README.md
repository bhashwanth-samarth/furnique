# Furnique Furniture Website

A responsive furniture business website built with HTML, CSS and JavaScript.

## Features
- Responsive modern furniture storefront
- 30 sample products
- Category filters
- Style filters
- Search
- Product quick-view modal
- Shopping cart with localStorage
- Enquiry button
- Newsletter form
- Responsive mobile navigation
- GitHub Pages ready

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files while preserving the folders.
3. Open repository Settings → Pages.
4. Select the branch containing the files and the root folder.
5. Save and open the generated Pages URL.

## Customize
- Products: `js/products.js`
- Main design: `css/style.css`
- Website behavior: `js/app.js`
- Main page: `index.html`
- Replace the sample Unsplash image URLs with your own product photos.
- Change `hello@example.com` in `js/app.js` to your real business email.

## Important
The product information and images in this project are demo content. Replace them with your own business data before publishing commercially.
